    --lam-pde 0.5 \

    --feature-normalize \
    --feature-normalize-mode global_fixed

Launch path details
- The script builds a RunConfig with defaults and applies CLI overrides.
- It loads one of: `Allen_Cahn*`, `burgers`, or generated `burg_gen`.
- It constructs a PDETrainDataset with coordinate normalization and stride-based subsampling.
- If `feature_normalize` is enabled with `feature_normalize_mode=global_fixed`, it computes one training-dataset L2 scale per primitive feature and freezes those scales for the full run.
- If pretrain_epochs > 0, it first fits the SIREN u_model to data only.
- It then jointly trains u_model and the EQL v_model using data and PDE losses.

Loss components in the active training path

1. Pretraining phase: utils.fit_utils.fit_model_to_data(...)
- data MSE loss
- TV regularization via tv_terms
- optional data L1 loss via lam_l1_data
- optional smooth-L1 parameter sparsity via lam_sparse_eql

- Pretraining total loss:
  loss_data + loss_tv + loss_l1_data + loss_sparse_eql

2. Joint phase: utils.fit_utils.fit_data_and_pde(...)
- data MSE loss weighted by lam_data
- PDE consistency MSE loss weighted by lam_pde
- parameter L1 penalty on v_model weighted by lam_param_l1
- data L1 loss weighted by lam_l1_data
- PDE L1 loss weighted by lam_l1_pde
- smooth-L1 sparsity on v_model parameters weighted by lam_sparse_eql
- TV regularization via tv_terms

- Joint total loss:
  loss_data + loss_pde + loss_param_l1 + loss_l1_data + loss_l1_pde + loss_sparse_eql + loss_tv
